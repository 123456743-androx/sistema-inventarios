# Sistema de Inventarios

## Descripción

Sistema web desarrollado para la administración de productos mediante operaciones CRUD (Crear, Leer, Actualizar y Eliminar).

El sistema permite:

* Registro de usuarios
* Inicio de sesión
* Agregar productos
* Editar productos
* Eliminar productos
* Buscar productos
* Dashboard de información
* Modo oscuro
* Alertas visuales

## Tecnologías Utilizadas

* Node.js
* Express.js
* MongoDB
* MongoDB Compass
* HTML5
* CSS3
* JavaScript
* GitHub

## Requisitos

* Node.js instalado
* MongoDB instalado o MongoDB Compass
* Navegador web moderno

## Instalación

1. Clonar repositorio

git clone https://github.com/123456743-androx/sistema-inventarios.git

2. Entrar al proyecto

cd sistema-inventarios

3. Instalar dependencias

npm install

4. Ejecutar servidor

node server.js

## Acceso

Abrir navegador:

http://localhost:3000

## Funcionalidades

* Registro de usuarios
* Inicio de sesión
* Administración de productos
* Búsqueda de productos
* Edición de productos
* Eliminación de productos
